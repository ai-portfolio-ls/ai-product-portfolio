# RiverSR · 河水锶同位素预测与模型评估

**为未采样河流建立预测基线，并判断结果能支持什么研究用途。**

河水的 ⁸⁷Sr/⁸⁶Sr（锶同位素比值）可为环境差异和生物来源研究提供线索，但实测无法覆盖所有河流。这是我在种梦星辰阶段开展的中国科学院合作项目；我独立完成这里展示的数据整理、特征、模型训练、验证和运行工程，并推进下游应用设计。

## 模型做成了什么

早期 Full50 / Base V3 以 5,600 个站点建立 RF、XGBoost 基线，交付冻结数据、配方、原始留出预测与正式模型。严格隔离测试对应陌生水系上的迁移，避免把训练拟合当成未知地点表现。

![正式留出预测揭示高值误差集中](demo/assets/prediction-diagnostics.png)

RF 在同条件下的 pooled RMSE 为 0.017235，比 XGBoost 低 2.76%，可作为该阶段连续预测基线。但 136 个高值站点只占 2.43%，贡献 82.90% 平方误差。29 个极高值点在训练拟合中全部命中，站点均值留出预测却为 0/29。因此连续预测和高值发现需要分别验收。[原始输出、算法比较与重算](demo/README.md#模型结果如何改变交付范围)

## 一个站点怎样改变使用判断

站点 `bef26300f5bf4000` 的实测值为 0.896269，三次严格留出预测为 0.724092、0.726249、0.722047。预测彼此接近，却一致低估，说明重复稳定不能直接解释为结果可信。

该例按极高值组内绝对误差中位排名选取，是历史回放。可按站点 ID 检查输入、来源、冻结划分与三次预测；已知实测区间仅用于事后诊断，不能直接作为未知地点的模型路由。[四类站点与完整追溯](demo/README.md#单站复核输入留出结果与使用判断)

## 两项决定：按使用条件验证，按增量收益采用

### 新支流与完整陌生水系分别评估

留出支流时，下游观测仍可能向评估泄漏信息。我设计不依赖同位素响应的支流划分，并在训练和选参时剔除待测支流下游站点。在该阶段 2,577 个适用站点上，站点均值留出 RMSE 为 0.01334、R² 为 0.425。该结果支持新支流的单独适用范围，不能替代陌生完整水系成绩。[设计与结果](src/river_sr/training/base/v2/RESULTS.md)

### 新特征有领域意义，也要证明维护价值

后期 Human17 在相同 5,517 站点、相同测试划分上比较自然基线与新增人类活动信息。修复坝库 2015 年时间规则后重跑配对分析，三算法仍未通过整体增量标准。因此保留 Natural90 主基线，未增加正式人类活动预测层；该结论限定于当前代理变量的预测收益。[修复、配对结果与材料范围](evaluation/later-research-records.md#3-human17修复时间口径后重跑配对实验)

区域化、残差修正和过程特征的未采用结果，推动研究从继续调参转向输入信息与困难环境。[完整演进与停止依据](docs/decision-timeline.md)

## 应用探索的当前边界

早期正式模型与结果已收录；Natural90 / Human17 及生物基准目前依据历史执行回报，部分原始图表、模型未收录，不称本机已逐项重算。生物基准完成资料与协议准备，下一步才做独立水—生物对照及来源验证。[研究使用场景与应用规划](docs/case-study.md)

[地图原型](demo/README.md#地图原型探索研究结果的查询方式)使用合成数据，尚未连接真实模型。它探索查询表达，不能作为来源概率已验证的证据。不同阶段的样本、划分与指标分别解释，不拼接成性能增长曲线。
